# Memory Game

## Описание
Классическая игра "Найди пару" на Pygame. Нужно открывать карточки и находить одинаковые пары.

## Демо
[Ссылка на видео демонстрации](https://vk.com/away.php?to=https%3A%2F%2Fyoutu.be%2FlgrFdBbUjAk%3Fis%3DxmBiYepug18fy_OC&utf=1)

## Технологии
- Python 3.8+
- Pygame 2.6.1

## Установка и запуск
```bash
pip install pygame
python memory_game.py
