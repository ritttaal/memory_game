# Memory Game

## Описание
Классическая игра "Найди пару" на Pygame. Нужно открывать карточки и находить одинаковые пары.

## Демо
[Ссылка на видео демонстрации](https://youtu.be/ССЫЛКА)

## Технологии
- Python 3.8+
- Pygame 2.6.1

## Установка и запуск
```bash
pip install pygame
python memory_game.py
